# Lucy Baia · @lucybaia

**DevOps na prática: containers, pipelines e deploys confiáveis, do laboratório à produção.**

## Sobre mim

- Desenvolvedora full-stack em um hospital militar em Brasília, mantendo em produção um sistema Laravel/MySQL (DRH_V2 / SGP-MD).
- Lidero a adoção de cultura e práticas DevOps no sistema do hospital: CI/CD, containerização e deploys com gate. Sou a única pessoa do time com experiência em Docker.
- Experiência prática com Docker, GitHub Actions, Kubernetes (kind), ArgoCD, Prometheus/Grafana, Terraform e Ansible.
- Estudante de Análise e Desenvolvimento de Sistemas no CEUB, com formatura prevista para junho de 2027.

## Projetos em destaque

### [devops-playground (DevStation)](https://github.com/lucybaia/devops-playground)

Laboratório pessoal de DevOps de ponta a ponta. A base é uma aplicação própria (FastAPI + React), usada como caso real em cada etapa:

| Fase | O que foi feito |
| --- | --- |
| Containers | Docker multi-stage para backend e frontend |
| CI | Pipeline com GitHub Actions |
| Orquestração | Kubernetes local com kind |
| GitOps | Deploy contínuo com ArgoCD |
| Observabilidade | Métricas e dashboards com Prometheus e Grafana |
| IaC | Infraestrutura com Terraform |
| Automação | Configuração com Ansible |

As 7 fases planejadas estão concluídas, e um glossário documenta o que aprendi em cada uma.

### CI/CD no sistema hospitalar

Montei do zero o pipeline de CI/CD no GitLab usado pelo time de desenvolvimento do sistema do hospital:

- GitLab Runner em Windows, com jobs em PowerShell
- Testes automatizados com PHPUnit
- Documentação do ambiente de testes para o time

### Open source

Contribuições na área de observabilidade, em [prometheus-community/helm-charts](https://github.com/prometheus-community/helm-charts) (chart `kube-prometheus-stack`).
